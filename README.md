# DataScience1

Course project on how PCA dimensionality reduction and OLS regression affect prediction error under different training-data sizes.

## Summary

The project compares models by mean squared prediction error (MSPE). PCA helps reduce overfitting when training data is limited, while OLS improves as more data becomes available and can use the full feature set effectively.
